## Decisiones clave
- Contraseñas SHA1 calculadas en SQL Server (`HASHBYTES`), no en VBScript. El login acepta hash o texto plano heredado.
- Cursor `adUseClient` en la conexión para poder usar `RecordCount`/`MoveFirst`.
- Navegación PJAX: el reproductor vive fuera de `#main-view`, así no se reinicia al navegar.
- Subidas multipart con `Request.BinaryRead` + `ADODB.Stream` (sin componentes externos).
- Conexión con fallback MSOLEDBSQL → SQLNCLI11 → SQLOLEDB.
